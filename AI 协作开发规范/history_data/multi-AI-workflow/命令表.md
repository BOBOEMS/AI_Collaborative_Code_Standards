## 调用架构


## D

配置取自角色总表 D，实际 Agent/model/transport 从项目批准的 preset 合成。模型名、强度和 UUID 不重复硬编码进统一入口命令。

```powershell
# 预览预设（只读）
python $entry --stage '<阶段>' --role D --mode Inspect --preset '<已定义D预设>'

# 准备配置，然后按项目要求提交配置和同步登记页
python $entry --stage '<阶段>' --role D --mode Configure --preset '<已批准D预设>' --task-file '<已批准切换记录绝对路径>'

# 激活切换，随后按项目要求保存回写的真实ID
python $entry --stage '<阶段>' --role D --mode Switch --task-file '<已批准切换记录绝对路径>'

# 新阶段确实尚无D时创建
python $entry --stage '<阶段>' --role D --mode Start

# 给当前绑定发送一轮任务；已有会话的继续任务也使用此入口
python $entry --stage '<阶段>' --role D --mode Send --task-id '<本轮任务ID>' --task-file '<已批准任务记录绝对路径>'
```

明确复用现有 D 时，Inspect/Configure 可按现有接口加 `--continue-id '<原生ID>'`；绑定激活仍走 Switch。模型、transport 或参数变化不能直接沿旧绑定 Send；旧任务回报仍使用派发时的收件绑定。

现有原生驱动保持独立：[Antigravity PS 入口](C:/bobo_document/work/Reuse_RTU/6.Tools/scripts/agent_antigravity.ps1) → [原生 RPC](C:/bobo_document/work/Reuse_RTU/6.Tools/scripts/agent_antigravity.py)，[DSH 桌面 API](C:/bobo_document/work/Reuse_RTU/6.Tools/scripts/agent_dsh.cjs)，以及统一入口中的 Codex App/CLI 分支。Agent 差异由适配器处理，不统一拼造 effort/context 参数。

当前项目存在精确原生 Thinking 模型预设；旧 flash/high 协议目标不能代替原生模型映射证明。模型可用性和效果沿其实际证据，不仅看命令别名或模型自报。

## 会话绑定与同步

真实会话 ID 保存在项目唯一执行配置；展示登记由该配置同步。命令表只保留模板，操作时读取当前阶段的明确角色绑定。

配置目标或 Agent 变化时：角色总表 → 对应角色命令。正式采用时再按现有接口准备项目 preset、核对原生参数、激活绑定并保存返回的 ID；修改协议文档不会自动修改项目 JSON 或运行会话。

新建回执不确定时核对原创建记录，不盲目再建；Send 回执不确定或同一结果再次通知时核对原任务，不重复派发已安排工作。原会话 ID、收件人和任务对象在历史记录中保持可追溯。
