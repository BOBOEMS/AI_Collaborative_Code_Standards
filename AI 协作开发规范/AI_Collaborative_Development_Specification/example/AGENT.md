## 2. 新会话与压缩恢复

每次新会话、个别会话替换、上下文压缩或中断恢复，相关动作前重新取得本文件、[协议入口](../AGENT.md)、[工作流恢复规则](../多AI会话工作流规范.md#session-recovery)的当前原文，再读本表中的状态、角色登记、当前版本范围、M01 计划与设计及直接依赖的共用约定。

按 [ROLES.md 第 8 节](ROLES.md#8-新会话和压缩恢复的实际读取入口)补读本角色任务、材料和证据。摘要只用于定位，当前原文已完整加载时可直接使用。核对旧任务、对象和资源后，首次正常回报简述阶段、角色、对象及下一步。

当前 M01 已结束，不恢复其任务或自动进入 M02。实际进入下一阶段须按计划确认依赖和授权，再建立全新 ABCDE；本例没有创建真实会话。

## 3. 文件、工具与 Git

当前方案覆盖维护，工作经过进入 `records/`，原始材料进入 `evidence/`。C/D/E 工具按用途和会话分目录、索引说明；复制复用注明来源并核对当前对象和输出。

ABCDE 每批文件操作交付前按[Git 规则](../多AI会话工作流规范.md#git-delivery)提交，阶段结束由 A 核对并推送已确认远端。实际仓库和目标须先在项目入口/配置中确定；本示例中的演示回执不能用作执行命令。
