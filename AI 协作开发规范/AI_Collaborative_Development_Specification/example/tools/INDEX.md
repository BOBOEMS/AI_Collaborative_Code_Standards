# 示例内部工具索引

本目录对应项目 `AI/tools/`。工具按用途及会话分开，当前只展示 [M01 工具](M01/INDEX.md)。无 A/B 脚本，不创建空目录。

三个脚本使用 Python 标准库，仅离线处理教学配置或合成数据，不运行固件、不连接设备，也不创建 AI 会话。命令从本示例根目录执行；实际项目核对脚本参数、对象、输出和授权后再复用。

复制前阶段脚本到当前阶段或替换会话目录时，在本层和对应会话索引登记实际入口，注明来源，按实际差异检查；来源证据保留，当前输出使用新轮次路径。具体规则见[内部工具规范](../../文档组织与维护.md#internal-tools)。
