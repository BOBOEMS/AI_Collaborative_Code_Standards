# 共用设计：镜像区域与安装保护

规定位置：`AI/shared_design.md`。由当前 B 维护，M01 安装恢复、M02 配套包、M03 远程安装共同引用。仅当前 M01 使用的内部流程在 [DESIGN.md](milestones/M01/DESIGN.md)维护。文件维护、工具分工及 Git 协作沿 [ROLES.md](ROLES.md)及所引规范读取，模型和会话登记见 [SESSIONS.md](SESSIONS.md)；本文件只保存共用技术约定。术语见 [PROJECT.md](PROJECT.md#术语与阅读说明)。

## 1. 采用依据和边界

本例依照[总体方案](PROJECT.md#5-关键约束与总体取舍)的单 App 槽、外部备份策略演示共用约定。以下片内容量取自背景工程，NOR 偏移为本教学场景假定；采用真实工程时须核实擦写粒度、链接地址、驱动和已有业务区，禁止直接使用教学偏移操作设备。

本例只有一个共用主题，集中维护本文件。独立主题增多且确需分册时，按[共用设计规则](../总体方案设计规范.md#shared-design)拆入 `design/` 并更新入口。

## 2. 共同采用的区域约定

下表单位均为字节，偏移相对于所属存储器，不是可直接使用的 MCU 地址。

| 存储器与区域 | 起始偏移 | 长度 | 共同限制 |
|---|---:|---:|---|
| 片内 Flash：Boot | 0 | 32768 | 升级流程不得擦写 |
| 片内 Flash：App | 32768 | 229376 | 镜像不能越出此区域，链接与安装位置须配套 |
| 外部 NOR：教学元数据区 | 0 | 8192 | 本例保留共同描述信息，不代表真实产品已有布局 |
| 外部 NOR：旧 App 备份区 | 8192 | 229376 | 仅验证合格且提交完成的备份可供恢复和维修准入 |

片内总容量为 262144，外部 NOR 总容量为 8388608。表外已有业务区不得因 OTA 擦写。元数据具体编码、擦写粒度和真实驱动入口在实际采用前确认，本例不生成可烧录布局。

FRAM 背景容量为 2048，旧声明不一致及 URL 保存失败由 M03 前的实际存储决定处理；M01 不启用或宣称修复 URL 写入。

## 3. 共同保护和交接信息

安装信息至少能关联目标镜像的版本、长度、完整性校验和当前阶段。备份只有实体完整性验证通过且完成有效提交后，才能作为合格备份；部分写入或仅存在成功标志不能单独证明其合格。

覆盖 App 前必须满足获批恢复条件。维修入口没有合格备份时拒绝安装并保持当前 App 区不变；普通升级、试用恢复及维修准入采用各自已确认前提，不能以一条模糊成功状态代替判断。

校验算法和线格式沿真实工程已确认约定，具体字节定义不由本教学布局推断。候选及部署材料须可追溯到实际构建，DEMO 名称仅用于说明关联。
