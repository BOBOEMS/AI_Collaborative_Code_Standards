# 嵌入式 AI 协作开发规范 V3.0

更新日期：2026-10-17。

本规范面向小团队的嵌入式产品开发，按“总体方案设计 → 里程碑划分 → 多 AI 会话执行”的顺序逐步制定。产品开发按 V1 初版、V2 优化、V3 深度研究区分工作深度，先完成当前版本已确认的功能和必要验证，再按实际需要迭代。

“V3.0”是协作规范版本；“V1/V2/V3”是产品开发的工作深度，两者分别使用。

AI 使用从 [AGENT.md](AGENT.md) 进入，按当前任务读取对应分册。项目采用时在已有入口明确范围和规范版本。
