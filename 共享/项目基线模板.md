# 项目基线模板

> 使用方法：用本模板核对项目元数据；已有 `PROJECT.md` 或项目基线时直接补齐缺项并引用，只有缺少承载位置时才复制为 `project_baseline.md`。语言专项配置同样复用现有权威记录。未知项保留“待填写”，不得凭经验补全。

| 项目项 | 当前值 |
| --- | --- |
| 项目/产品名称 | 待填写 |
| 仓库及主分支 | 待填写 |
| 项目负责人 | 待填写 |
| 协作方式及真实确认来源 | C：个人+AI / 多人团队；其他语言按分册适用方式；引用实际确认记录，既有项目不得默认切换 |
| 协作与技术规范版本、检查记录入口 | 待填写；个人+AI 须明确采用的 AI 协作规范，团队模式引用团队要求 |
| 当前发布/脚本版本 | 待填写 |
| 目标产品型号、硬件版本或板号 | 待填写 |
| 支持的产品变体 | 待填写 |
| 关键依赖/上游基线记录位置 | 待填写 |
| 变更与发布记录位置 | 待填写 |
| 本配置维护人 | 待填写 |
| 最近确认日期 | 待填写 |

使用对应分册补充技术事实：

- C 项目填写编译器、芯片布局、FreeRTOS、IRQ/DMA、资源和构建矩阵。
- LuatOS 项目填写模组/固件、打包映射、board profile、任务/事件、存储与升级矩阵。
