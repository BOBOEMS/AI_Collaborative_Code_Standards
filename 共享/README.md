# 共享治理文件

本目录保存协作方式的适用边界及多人团队治理要求。C 项目按已确认的“个人+AI / 多人团队”方式接入；未明确选择个人+AI 的既有 C 项目继续沿用原团队要求。LuatOS 按其分册已采用的模式执行，个人/小团队模式不强制引入多人流程。

| 文件 | 用途 |
| --- | --- |
| [团队治理与评审基线.md](团队治理与评审基线.md) | 协作方式与复用记录的入口；规则执行级别、团队 R0/R1/R2、评审人数和证据边界。 |
| [项目基线模板.md](项目基线模板.md) | 每个项目共用的产品、仓库、负责人、版本与确认日期元数据。 |
| [模块责任与轮值模板.md](模块责任与轮值模板.md) | 多人团队的主负责人、备份、轮值与交接字段；已有责任记录可直接引用。 |
| [豁免与紧急修复流程.md](豁免与紧急修复流程.md) | 有期限的规则豁免和生产紧急修复流程。 |

技术差异放在对应分册：C 的 IRQ/FreeRTOS/链接与 LuatOS 的任务/打包/低功耗不在这里重复描述。

模板用于检查字段是否完整，不强制另建文件。项目基线、技术配置、批准和检查结果各自保留一处权威记录；已有 `PROJECT.md`、里程碑或等价记录可直接承载。
