# C / FreeRTOS 项目技术配置模板

> 使用方法：项目初始化或技术配置变化时，用本模板和 [共享项目基线模板](../共享/项目基线模板.md) 核对字段。已有 `PROJECT.md`、专项配置或机器配置时直接引用并补缺项；只有缺少承载位置时才复制本文件，不默认另建两份配置文档。未确认项保留“待填写”，不得凭经验补全。

协作方式、采用规范及真实确认来源：引用项目基线，本文件不维护第二份选择记录。

以下表格可作为字段索引。现行技术值只维护一处；测量值、源码/产物标识和测试证据引用对应里程碑或已有测试记录，历史验证快照保持原版本。项目不使用的技术领域可整组标明不适用及依据。
